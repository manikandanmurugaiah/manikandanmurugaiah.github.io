# Dr. Manikandan M. — Academic Website

A lightweight, responsive academic portfolio designed for GitHub Pages.

## Before publishing
1. Replace `YOUR_EMAIL@example.com`.
2. Add your photograph.
3. Add verified Google Scholar, ORCID and GitHub URLs.
4. Replace placeholder publications with verified bibliographic details.
5. Add your CV as `documents/cv.pdf`.
6. Upload lecture PDFs/PPTs and update the resource links.
7. Review all public content before publishing.

## GitHub Pages
Create a repository named `<your-github-username>.github.io`, upload these files, then enable GitHub Pages from the repository's Settings → Pages.

The site is static HTML/CSS/JavaScript, so no server or database is required.
